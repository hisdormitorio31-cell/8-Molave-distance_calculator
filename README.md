# Distance calculator

## Description
```text
My program calculates distance using the distance formula for two points. The user will input the **x** and **y** coordinate of two points, and my program will use the distance formula:
**Distance = d = √(x2 - x1)2 + (y2 - y1)2.
```

## How to Run
```text
1. Open the program in VSCode or other IDEs.
2. Run the program.
3. Enter the `x1` value of the first point.
4. Enter the `y1` value of the first point.
5. Enter the `y2` value of the second point.
6. Enter the `y2` value of the second point.
```

## Input Needed
```text
x1 = the x coordinate of the first point.
y1 = the y coordinate of the first point.
x2 = the x coordinate of the second point.
y2 =  the y coordinate of the second point.
```
## Sample Output
```text
Enter x1: 3 
Enter y1: 4 
Enter x2: 8
Enter y2: 9 
The distance between the two points is 7.0710678118654755
```
